# Monitored_Airspace_Proyect
Información y avances acerca del proyecto propuesto para la Feria de Ciencias de la E.E.S.T. N7 "T.R.Q.". Se propone presentar, armar, gestionar y poner en marcha un dispositivo con las tecnologías de un radar funcionando como satélite para proteger el espacio aéreo argentino de ataques hacía nuestra soberanía nacional.
